每一条都是「改了不报错、只是静静地不对」的那一类。26–37 是第二版（对照 ZeppBridge 重做折射、给分段开关加上按住浮起）时踩到或预先避开的。遇到诡异现象先按症状在这里找。

### 1. 带投影的元素上挂位移滤镜，折射整片错位

Chromium 按「含投影在内的溢出范围」算滤镜坐标，整张贴图跟着挪。
→ 滤镜放 `::before`，投影留在宿主（`.lg-glass` 就是这么搭的）。透镜同理：外层不带投影，投影单独一层 `.lg-lens-sh`。

### 2. 滤镜区域写成 `userSpaceOnUse` 加 x / y

坐标原点跑到别处，贴图对不上。→ 用缺省的滤镜区域（每边比元素大 10%，外圈由 128 灰底兜住，不位移）。

### 3. 忘了 `color-interpolation-filters="sRGB"`

缺省是线性 RGB，贴图里的 128 被换算成约 55，等于每个点都往一个方向偏。→ 写在 `<filter>` 上。

### 4. 「采不到背景」（背景根）

一个元素的祖先如果带 `filter`、`opacity < 1`、`mask`、`clip-path`、`mix-blend-mode` 或 `backdrop-filter`，
这个祖先就成了它的「背景根」，它的玻璃只看得见背景根里面画过的东西，看不见页面。
→ 弹出动画只动 `transform`，**不做淡入**；透镜的淡入淡出只改子层的 `opacity`，外层只改 `transform`；
遮罩只调暗、**不模糊**（遮罩一带 `backdrop-filter`，里面的面板就只能采到遮罩）。
框架自带的过渡组件（淡入淡出）套在玻璃外面也会触发这一条。

### 5. `<button>` 的默认底色

浏览器给 `<button>` 一层浅灰底，垫在玻璃下面，同一种玻璃一个透一个实。→ 玻璃宿主一律 `background: transparent`（`.lg-glass` 已写）。
自己的样式表如果给 `button` 写了全局背景，记得对 `.lg-glass` 排除。

### 6. 最近邻取样

位移滤镜不做插值。硬边（着色块的边、1px 的线）被折射会出锯齿；设备像素比为 1 的屏上 1px 细线可能整条消失；
边上拉开十倍的地方更是一级级台阶。
→ 滤镜在边上按位移大小叠一层模糊（m^1.6 加权，最外缘约 1px），顺带把台阶抹掉；中间不位移也就没有锯齿。
选中项上的悬停透镜不开折射；玻璃边宽不小于 10px；不在折射区里放 1px 的细线。

### 7. 透镜移动时字上划出一道缝、字在闪

两个原因叠在一起：变形中的透镜用着停稳时尺寸的贴图；透镜盖在字上面，高光环从字上划过去。
→ 透镜只在停稳后淡入折射层；透镜垫在字底下（透镜 z 1，项 z 2，滑块 z 0）。

### 8. 滚动容器里的玻璃层跟着滚走

绝对定位的 `::before` 以滚动容器的内容原点为准。→ 玻璃宿主自己不滚，让里面的某一块滚（侧栏不滚、`.lg-nav` 滚；长菜单包一层滚动容器）。

### 9. `> * + *` 这类间距规则把插进去的元素算进去

在最前面插一个透镜，原来的第一项就吃到 `margin-left`，整排挪位。
→ 脚本插的元素一律**追加在末尾**、绝对定位、`margin: 0 !important`。

### 10. 页面脚本按 `className` 全等判断

比如 `if (prev.className === 'toolbar') return;`（别装第二遍）。玻璃脚本多加一个类，它就认不出来、再插一条。
→ 玻璃脚本的状态只写 `data-*`（`data-lg-slider-on`、`data-lg-refract-on`、`data-lg-item`……），**不增删页面元素的类名**。
`scripts/check.mjs` 专门拦这一条。

### 11. `innerHTML` 整片重画把插进去的元素冲掉

→ 状态存在宿主元素上（`__lgL`、`__lgT`、`__lgR`），元素没了就按状态重建；用 `MutationObserver` 发现变化，一帧最多对一遍。
所以列表每按一次方向键整片重画，光标滑块照样连续地滑。

### 12. `CSS.supports` 对 `backdrop-filter: url()` 说谎

Safari、Firefox 回答「支持」，然后静默丢掉整条声明——连模糊都没了。→ 按浏览器品牌判断（`navigator.userAgentData.brands` 里有 `Chromium`，
或 UA 里 `Chrome/≥90`），非 Chromium 的 `backdrop-filter` 里永远不写 `url()`。

### 13. 类名撞车

命令面板里危险页的条目带着 `.danger` 类，吃到了危险按钮的整套样式，被画成一整条红色胶囊。
→ 本套件的类都带 `lg-` 前缀，就是为了不撞；自己新加类名前先全局搜一下有没有同名的按钮 / 控件样式。

### 14. 宽行放大让左边的字跳

放大以中心为原点，500px 宽的一行放大 2%，左边的字就往左跳 5px。→ 宽列表项 ≤ 1.5%，表格整行 0。
按下的形变同理：透镜横向鼓 6%、那一项缩 3.5%，在 500px 宽的命令面板项上就是透镜顶出面板 15px、左边的字跳 9px；
在 1150px 宽的表格行上，透镜鼓出去 35px，被表格裁掉，圆角也没了。→ 按像素封顶（透镜鼓 ≤ 12px、项缩 ≤ 6px），整行不往外鼓、往里收一点。

### 15. 软件渲染很卡

远程桌面、虚拟机、没装显卡驱动时浏览器用 CPU 画图（SwiftShader、llvmpipe、Microsoft Basic Render），
每块玻璃每帧都要 CPU 做一遍模糊和位移。→ 自动档下检测到就先不折射；掉帧也自动降；用户还能手动点「精简」「关闭」。

### 16. 背景一动，玻璃就要重算

玻璃背后的东西每变一次，浏览器就要把那一块重新模糊、重新折射。
→ 页面底用纯色，侧栏背后滚动时不变；带折射的玻璃只留给背后真有内容的那几块；模糊半径最大 24px。

### 17. HDR 高光不亮或边缘发黑

PNG 没带 `cICP`（浏览器当成普通 sRGB）、或 alpha 预乘了。→ 用 `scripts/hdr_png.py` 生成：16 位、`cICP 9/16/0/1`、直通 alpha。

### 18. 老浏览器上整页脚本都不执行

一个箭头函数就是语法错误，整个文件不执行。→ 玻璃脚本只用 ES5（没有 `=>`、`let` / `const`、模板字符串、`class`、展开语法）。
`scripts/check.mjs` 会拦。

### 19. 无头浏览器截图看不到折射

无头 Chromium 用软件渲染，自动档先不折射。→ 截图前 `localStorage.setItem('lg.glass', 'full')`（`scripts/shoot.mjs` 已经这么做）。

### 20. 开关的几档看起来一样，就等于开关坏了

早先的定义是「精简 = 去掉折射」「关闭 = 去掉透明」：形状、高光、透镜、动画全都还在，面板背后又是纯色，
三档截图逐像素比只有 0.2% 的像素不同；而自动档在远程桌面上本来就是「只模糊」，点「精简」完全没变化——
用户的原话是「按钮似乎没反应」。
→ 三档按**用户看得见、摸得着**的东西分（精简去掉流动动画，关闭连透镜、滑块、高光环一起撤）；点了当场弹一句提示说明这一档是什么样。
以后加档位或开关，先截图比一比，肉眼分不出来的就不是一档。`scripts/shoot.mjs` 会在 DOM 与像素两头验。

### 21. 「关闭」时开关自己跟着消失

开关原先按 `html:not([data-lg-lens])` 隐藏（没有脚本就不摆出来）；「关闭」会撤掉 `data-lg-lens`，于是一点「关闭」开关就没了、再也点不回来。
→ 脚本在不在另用 `data-lg-js` 标，开关的显示只看它。

### 22. 满屏的底纹再轻也是噪声

为了让玻璃「有东西可折」给整页垫了一层点阵、在登录卡背后铺了一面大字，上线后都被嫌丑、太花。
→ 页面底回到纯色。想让玻璃显出来，靠的应该是真内容从它底下经过，而不是给整个页面铺花纹。

### 23. `:active` 写在 `:hover` 前面

两条选择器一样具体时后写的赢；写反了，按下时还是浮着、不缩。→ 按下的规则写在悬停后面。

### 24. 白按钮的指尖光看不出来

白光打在白按钮上等于没打，用户觉得「这个按钮悬停没有动画，和别的按钮不统一」。
→ 所有按钮悬停是同一套动作（浮起 1px + 投影加深 + 指尖光），白按钮的指尖光带一点主色（`--lg-sec-glow`）。

### 25. `data-theme` 写在 `<body>` 上

`--lg-pro-sh` 这类「引用了别的变量的变量」只在 `:root` 上定义一次，在 `<html>` 上求值；
深色令牌若写在 `<body>` 上，`<html>` 上算出来的还是浅色那套。→ `data-theme` 写在 `<html>` 上。

### 26. 边上的字被画两遍、有一道镜像：位移曲线折叠了

输出上离边 s 的这一点取的是 s + D(s) 处的内容。只要某处 D′ < −1，取样位置就先往回走再往前走——同一段内容被画两遍，
中间夹一道镜像。按斯涅尔定律 + 凸超椭圆剖面算出的位移正是这样：边宽 18 时从边缘往里 0、1、2、3 px 取到 8.9、5.6、5.0、5.1。
「位移从边缘往里单调减小」并不够，要的是**取样位置单调**。
→ 用 `D(s) = 0.45 · b · (1 − s/b)²`：最外缘 1 + D′ = 0.1，处处为正。`displacement_map.py --selftest` 验的就是这一条。

### 27. 边上看着像缩小了，字在边上重影：往外取样

让边上「映出玻璃外面的东西」听上去很像透镜，但位移往里递减时往外取样，数学上是把更多内容挤进更窄的地方——缩小，
同一段字还被画两遍（ZeppBridge 第三版就是这样，滚轮边上的字出了重影，第四版改了回来）。
→ 往里取样、越靠边位移越大，边上是放大。

### 28. 折射的透镜浮起来是一块发暗的方块

透镜自己或祖先带 `filter` / `backdrop-filter` / `mask` / `clip-path` / `mix-blend-mode`（背景根，见 #4）时，
Chromium 只把那个祖先里面的东西交给 `url()` 滤镜，输出还会把原图换掉——不只是采不到背景，而是一块发暗的方块。
→ 脚本每次摆折射前顺着祖先往上查，有就不开折射、只留模糊。要在玻璃面板里放会折射的东西，面板的毛玻璃画在伪元素上
（`.lg-glass` 就是这么搭的），别画在宿主上。

### 29. 折射的透镜一动就发糊

`scale()` 会把透过它的东西重采样一遍：透镜里的字发糊，贴图也和元素对不上。
→ 会折射的元素只平移（`translate3d`），大小写在 `width` / `height` 上。分段开关浮起的透镜就是这样，所以一路都能折射；
悬停透镜要做水滴形变、按下的果冻，所以只在停稳、没有缩放时才淡入折射层。

### 30. 拖窗口、透镜变宽时折射一顿一顿

每个尺寸重画一整张贴图（`<canvas>` → data URL → 浏览器再解码一遍）跟不上逐帧变化的尺寸，只能先撤掉折射、停手再算。
→ 贴图切成九宫格，尺寸变了只改八个 `<feImage>` 的 x / y / width / height；只有圆角、边宽变了才画新的。

### 31. 换选中时旁边的项被挤动

选中项是粗体，粗体比常规体宽，按钮按内容收紧的话，选中那一项一变宽就把后面的项往外推（拉丁字母更明显）。
→ 按钮宽度按粗体留：脚本把字写进 `data-lg-label`，样式表在 `::after` 里放一份隐形的粗体撑宽。

### 32. 拖着换完选中，松手后选中又跳回原处

拖完松手，浏览器还会补一下 click：落在按下的那一项（拖出去又拖回来时）或整条上。脚本替用户点了新的那一项之后，
这一下 click 再落到原来那一项上，页面就把选中又改回去了。
→ 拖动后紧跟的那一下 click（`isTrusted` 为真）在捕获阶段吞掉；脚本自己点的（`element.click()`，`isTrusted` 为假）放行，
而且放在 `setTimeout(0)` 里，排在浏览器那一下后面。

### 33. 分段开关按一下没反应

一按下就 `setPointerCapture`，松手的 `pointerup` 就落在了捕获它的整条上，click 也跟着落到整条上——绑在按钮上的点击处理收不到。
→ 指针捕获等横向动了 5px、真开始拖了才设；只按一下不动时，click 照常落在按钮上。

### 34. 截图里矮的玻璃条底下的字没被模糊

Playwright 的无头 Chromium（软件渲染）里，`backdrop-filter: blur()` 在元素边上是透明的：离边几个模糊半径以内，
原来清楚的内容会透出来。400px 高的面板只有边上一圈这样；58px 高的导航条整条都在「边上」，截图里底下的字几乎是清楚的，
边缘折射在这种条上还会出一圈发灰的厚边（折射把里面更不透明的那部分搬到了边上）。实机 Chrome 的毛玻璃不是这样（同一页面上的保存条底下就是糊的）。
→ 看矮条的模糊要在实机上看，别凭无头截图下结论；矮条不默认开边缘折射。最小复现：同样 `blur(16px)`，盒子 60px 高时字读得出来，400px 高时正中糊成一片。

### 35. 拖动时滑块一下飞出几百万像素

拖动时滑块追手指用的是一根很硬的弹簧（0.12s，刚度约 2700）。半隐式欧拉在一步 34ms 的慢帧里（无头浏览器、卡顿时）阻尼项一步就冲过头，
越冲越大，几帧以后位置是四百多万像素。
→ 一帧拆成不超过 4ms 的小步再积分（`step` 里做），所有弹簧都更准；时长和回弹不用改。

### 36. 鼠标划过表格最后一行，白色滚动条闪一下

表格外框是 `overflow: auto`（窄屏能横着滚）。透镜从倒数第二行流到最后一行时，位置弹簧带回弹，往下多冲 1px——
外框的滚动高度从 440 变成 441，竖滚动条出来；它占掉宽度，表格横向又溢出，横滚动条也出来；回弹收回去，两条一起消失。
系统设置成「总是显示滚动条」（Mac 接了鼠标就是）时就是一道白条一闪。侧栏菜单、命令面板列表是同一类滚动容器，最后一项也会这样。
→ 面板是滚动容器时，透镜和滑块每一帧画出来的外框都挪回内容范围（`scrollWidth` × `scrollHeight`）里；透镜一直被关在里面，量到的就是内容本身。
`shoot.mjs` 在表格和侧栏菜单的最后两项之间来回划，逐帧盯着滚动尺寸。

### 37. 点另一项，选中像是从一个按钮「跳」到另一个

逐帧看是三样东西各走各的：鼠标一到终点，**悬停透镜**先出现在终点那一项底下；页面一点就把终点标成选中，**选中色**立刻换过去；
真正浮起来的那块透镜跟着液态滑块的中心走，而滑块后沿用慢弹簧，**透镜被拖在后面**，到得很晚。眼睛看到的是「终点先亮、一块东西后到」——跳。
→ 只留一块玻璃：按下那一刻悬停透镜立刻撤掉、飞完之前不再出来；浮着飞的时候两条边用同一根弹簧，整块平移；
选中色跟着离玻璃最近的那一项走（`data-lg-fly` + `data-lg-near`），终点等玻璃到了才亮。
`shoot.mjs` 点最后一项时逐帧记：悬停透镜不许出来，选中色要依次经过中间的项。
