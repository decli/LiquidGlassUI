# 设计规范（定稿）

长什么样、多大、什么颜色、怎么动。做视觉决定、给新组件定尺寸、或者核对实现有没有走样时读这份。
这些数值是多轮真机评审后定下来的（每一轮改了什么、为什么，见 `design-decisions.md`），没有特别理由不要凭感觉改。

## 1. 设计原则（按优先级）

1. **可读性第一。** 任何让字变难读的效果都不要。玻璃底色保留 58% 以上的不透明度，背后是正文的弹出层 78% 以上；
   内容区（卡片、表格）是实心的。玻璃上的字按最坏情况算：背后是最深的内容时正文仍 ≥ 4.5:1。
2. **降级不能坏功能。** 老浏览器、远程桌面、软件渲染的显卡上，效果可以少，功能一样都不能少，也不能卡。
   不加载脚本页面照样能用。
3. **不碰业务。** 玻璃层只读页面、只写 `data-*` 属性、内联样式和它自己插进去的元素。
4. **一致。** 所有能点的东西用同一种反馈（透镜 / 浮起 + 指尖光），所有多选一用同一种控件（凹槽 + 滑块），
   同一个功能只有一个入口。不允许「这里有玻璃、那里是普通菜单」。
5. **安静。** 页面底是纯色，不铺底纹；组标题是小灰字；快捷键数字平时藏着。玻璃靠真内容从它底下经过显出来。

## 2. 分层：哪些是玻璃

| 层 | 元素 | 材质 |
|---|---|---|
| 页面底 | `body` | 纯色（浅 `#e8ecf2` / 深 `#0e1217`） |
| 控制层（玻璃） | 侧栏、页头的胶囊、弹出菜单、命令面板、登录卡、工具条、底部保存条、浮动提示、玻璃提示 | 模糊 + 高光环（+ 背后有内容的才折射） |
| 内容层（实心厚玻璃） | 卡片、表格、表单分组 | 不透光；半像素轮廓 + 上沿 1px 亮线 |
| 控件 | 按钮、输入框、分段开关 | 着色玻璃胶囊 / 白玻璃胶囊 / 玻璃凹槽 |
| 交互反馈 | 透镜、液态滑块、指尖光 | 清玻璃 / 着色玻璃 |
| 按住时浮起 | 分段开关被按住的滑块 | 盖在字上面的清玻璃透镜：只折射、不铺色、不模糊 |

**折射只给背后真有内容的玻璃**：弹出菜单与命令面板（盖在正文上）、底部保存条（表单从底下滚过）。
侧栏、页头胶囊、登录卡背后是纯色页面底，折了也看不出来，白花显卡。以后它们背后有了内容（比如有背景图的页面），再用 `data-lg-refract` 打开。

## 3. 令牌

全部是 `--lg-*` CSS 变量，定义在 `liquid-glass.css` §1，浅色、深色（显式）、深色（跟随系统）三块。

|---|---|---|---|
| `--lg-bg` | `#e8ecf2` | `#0e1217` | 页面底 |

| `--lg-line` / `-strong` | `#dfe4ea` / `#c3ccd6` | `#2c333c` / `#3b434e` | 分隔线 / 输入框描边 |

| `--lg-good` / `-bg` | `#0f6b3a` / `#e2f5ea` | `#5fd394` / `#14301f` | 成功（深前景 + 浅同色底） |

| 令牌 | 浅 | 深 | 用在哪 |
|---|---|---|---|
| `--lg-tint` | 白 58% | 烟灰 `rgba(30,35,43,.58)` | 侧栏、胶囊（默认） |
| `--lg-tint-bar` | 白 66% | 烟灰 70% | 工具条、保存条（背后有内容滚过，要实一点） |
| `--lg-tint-menu` | 白 78% | 烟灰 82% | 弹出层、登录卡、提示（背后是正文，必须更实） |
| `--lg-tint-danger` | 浅红 72% | 暗红 62% | 危险态的胶囊 |
| `--lg-solid` | `#f8fafc` | `#1a2028` | 实色档（l0） |
| `--lg-rim` | 上沿纯白 → 42% → 10% → 8% → 下沿 62% | 同形、整体收暗 | 1.2px 高光环 |
| `--lg-sheen` | 左上角 62% 白的径向渐变 | 16% | 顶部柔光 |
| `--lg-edge` | 0.5px 轮廓，13% 黑 | 70% 黑 | 玻璃外轮廓 |
| `--lg-shadow` / `-lo` | 两层软投影 | 更深 | 浮起感（大面板 / 小胶囊） |
| `--lg-pro-*` / `--lg-red-*` | 蓝 / 红「上亮下深 + 同色光晕」 | 更亮一档 | 主操作、危险、侧栏选中 |
| `--lg-sec-*` | 白玻璃按钮；悬停光带 13% 主色 | 8% 白；悬停光 14% 白 | 次要按钮 |
| `--lg-well` / `--lg-seg-thumb` | 5.5% 灰凹槽 / 白滑块 | 6% 白 / 17% 白 | 分段开关 |
| `--lg-plate` / `-danger` | 白 72% / 红 6% | 白 4.5% / 红 7% | 侧栏分组底板 |
| `--lg-card-sh` | 0.5px 轮廓 + 贴地投影 + 上沿 1px 纯白亮线 | 同形收暗 | 卡片、表格 |
| `--lg-hl-*` | 透镜的底色、高光环、投影、指尖光 | 同形 | 透镜 |
| `--lg-scatter` | 纯白 | 白 45% | 折射的玻璃边上那层乳白（散射）；深色底上同样的白要淡一半，不然边上一圈发灰 |
| `--lg-lift-sh` | 0.5px 轮廓 14% 黑 + `0 8px 18px -8px` 浮起影子 | 0.5px 轮廓 10% 白 + 更深的影子 | 分段开关浮起的透镜 |
| `--lg-tab-sel` / `-sh` | 墨色 8.5% → 6% 的平胶囊，顶边 55% 白 | 白 15% → 7.5%，顶边 13% 白 | 玻璃导航条停着时的选中项 |
| `--lg-lift-spec` | 锥形渐变：左上（310°）纯白、右下（140°）90% 白两道斜对角高光，其余 20% | 同形，78% / 62% / 5% | 浮起透镜的 1.2px 高光环 |

**模糊半径随面板大小走**：侧栏与登录卡 18px、弹出层与命令面板 24px、浮动提示 20px、保存条 14px、工具条 12px、胶囊 10px。
不要超过 24px：更糊不更像玻璃，只是更费。

**换品牌色**只改 `--lg-accent`、`--lg-accent-hover`、`--lg-ring`、`--lg-accent-glass`、`--lg-pro-top`、`--lg-pro-bot`、
`--lg-pro-glow`、`--lg-sec-glow`（浅深两套都改）。`--lg-pro-sh` 这类「引用了别的变量的变量」不用动。

## 4. 外壳：侧栏与页头

### 4.1 侧栏

- 一块浮在页面底上的玻璃板：宽 236px（折叠 64px），离窗口边 12px，圆角 24px，模糊 18px，`sticky` 粘住。
- 侧栏自己不滚，中间的菜单区滚（侧栏若是滚动容器，玻璃层会跟着内容滚走）。
- 自上而下：品牌（32px 色块图标 + 名称 + 副标题 + 折叠钮）→ 菜单 → 弹性空白 → 底部（主题、玻璃两排分段开关 + 账号）。
- **一个功能只放一个入口。** 切换环境 / 工作区这类「每一页都要看得见」的东西放页头右上角的胶囊，不要在侧栏再放一张卡片。

### 4.2 菜单：iPadOS「设置」式分组底板

照 Apple HIG Sidebars 与 iPadOS「设置」：**每一组菜单项垫一块圆角底板**，一项属于哪一组，看它在哪块底板上就知道。

| 部分 | 规格 |
|---|---|
| 组标题 | 24px 高，12px、半粗（600）、次要色 `--lg-ink-2`、字距 .02em；**不比菜单项更黑更粗** |
| 收起箭头 | 12px，紧跟在组名后面（间隔 4px），不挂在一整行之外的最右边；展开朝下（旋转 90°），收起朝右 |
| 收起时 | 组名后面挂一个小数字（里面藏着几项）；收起的组里有当前页时组名染成选中色 |
| 危险组 | 组名后一个红色小标签；缺省收起；收起时箭头是红的；底板带一点红 |
| 组标题 → 底板 | 4px（离谁近就属于谁） |
| 底板 → 下一组标题 | 14px |
| 底板 | 圆角 14、内边距 4（14 = 菜单项圆角 10 + 4，同心）；白 72% + 半像素轮廓 |
| 菜单项 | 32px 高，圆角 10，左 8 右 10；项与项间隔 1px |
| 图标 | 16px 线性图标（描边 1.7），放在 20px 的格子里，**不垫圆形底色**——一列灰圆点会连成一根竖柱，把分组冲散 |
| 文字 | 13.5px，字重 450；选中 600、白字 |
| 快捷键数字 | 等宽 11px，平时透明，鼠标进了菜单或键盘在菜单里走时 50% 浮出来 |
| 选中项 | 蓝色着色玻璃（危险项红色），有脚本时是一块会流过去的液态滑块 |

- 最多两级（HIG：侧栏层级不要超过两级）。组名、菜单名简短，一眼能扫完。
- 折叠成图标轨时：底板照样垫着（没有字的时候靠底板分组），组标题只剩箭头（收起时加数字），
  危险项保留红底——没有文字时颜色是唯一线索；悬停出玻璃提示。

### 4.3 页头

- 左边页面标题 21px / 650，旁边一行 12.5px 的次要说明。
- 右边一排玻璃胶囊（`.lg-chip`）：36px 高、圆角 18、模糊 10px。**并排的胶囊必须同一种玻璃**，颜色、透明度一样。
- 状态胶囊：一个 8px 圆点（正常绿、异常红）+ 灰色标签 + 加粗的值 + 小箭头；危险态整颗染红。

## 5. 控件

### 5.1 按钮

| 种类 | 长相 |
|---|---|
| 主操作 `.lg-btn--primary` | 蓝色着色玻璃：上 `#4a86f0` → 下 `#2a66dc`，上沿 1px 32% 白高光、下沿 1px 8% 黑、同色光晕 `0 8px 18px -8px` |
| 危险 `.lg-btn--danger` | 同构，红 `#d8433f` → `#b3261e` |
| 次要 `.lg-btn` | 白玻璃：白 → `#f6f8fb` 渐变 + 0.5px 轮廓 + 上沿纯白亮线 |
| 尺寸 | 36px 高、胶囊形、13.5px；小号 30px、13px |
| 悬停（三种一样） | 浮起 1px（`cubic-bezier(.3,1.6,.5,1)` 0.32s）+ 投影加深 + 90px 指尖光跟着指针走；白按钮的指尖光带 13% 主色 |
| 按下 | 缩到 96.5%；按下的规则写在悬停后面 |
| 禁用 | 底 `--lg-surface-2`、字 `--lg-ink-3`、1px 内描边，不发光、不回弹；旁边写明为什么点不动 |

同一行的输入框与按钮一律 36px 高，只留水平内边距。

### 5.2 输入框：玻璃凹槽

- 底色比卡片略深（`--lg-fld`）+ 内侧一道浅阴影，像压进去的一道槽；圆角 9，描边 `--lg-line-strong`。
- 悬停描边加深；聚焦：底变亮、描边变主色、外发 4px 光圈 + 一点主色光，像槽里亮起来。

### 5.3 分段开关（所有「多选一」）

- 一道浅凹槽（`--lg-well`），选中那项上面浮一块白玻璃滑块（`--lg-seg-thumb` + `--lg-seg-sh`），有脚本时它会流过去。
- 常规：凹槽内边距 3、圆角 18；项 30px 高、圆角 15、13px；选中 600 字重。
- 小号：内边距 2、项 26px、12px 半粗；侧栏底部的主题 / 玻璃开关用小号、等分宽度。
- **按钮宽度按粗体留**：选中项是粗体，有脚本时每个按钮都按粗体的宽度留出来（`data-lg-label` + 隐形的粗体 `::after`），换选中不挤动旁边的项。
- **按住浮起**（iOS 26 标签栏，只在「完整」）：按住任意一项，白滑块浮起成一块清玻璃透镜（按的不是选中项就先飞到手指下面）——比这一行高两成、比项左右各宽 7px，
  盖在字上面，边上把字放大、弯折、泛一点彩边，正中原样；浮起 0.38s 带回弹，落下 0.26s 不回弹。
  不能折射的浏览器上不出透镜，滑块自己放大（横 5%、竖 10%）。
- **玻璃底下的字**：被玻璃盖住多少，字就放大多少（× `--lg-seg-mag`，常规 0.12、玻璃导航条 0.18，再乘浮起程度）、变粗多少、
  换成选中色多少——跟着玻璃连续过渡，飞过两项之间时一枚缩回褪色、一枚放大上色。放大以后的字再被透镜的边弯折、泛彩边。
- **拖**：按住任一项横向拖，透镜跟着手指走，被它盖住的项依次变成选中的样子；松手落到最近一项，快速一甩（≥ 0.6px/ms）往甩的方向最多再走一格。
  拖过两端整条像橡皮筋被拉长（≤ 轨道宽 5%、≤ 18px，越拉越费劲），松手弹回、略压扁一下再停；大力一甩整条朝甩的方向形变（≤ 3.5%）再回弹。
  点别的项时滑块浮着飞过去、完全浮起来而且到了才落下。「精简」照样能拖，只是不浮起、不拉长、不回弹。

### 5.3.1 玻璃导航条 `.lg-glass.lg-seg.lg-seg--glass`

iOS 26 的标签栏：浮在内容上面的一整块玻璃（放在能滚的内容底部，`position: sticky` 或 `fixed`），内容从它底下滚过。

| 部分 | 规格 |
|---|---|
| 条 | 胶囊形、内边距 4、模糊 16px、`--lg-tint`；整条的边默认不折射（要开写 `data-lg-refract="9 4"`） |
| 项 | 等宽铺满；最少 50px 高、圆角 999；图标 20px 在上、字 11.5px、500 字重在下，间隔 3px；常规色 `--lg-ink-2` |
| 选中 | 平胶囊 `--lg-tab-sel` + `--lg-tab-sel-sh`（浅色比玻璃略深、深色略亮，只有一道很淡的顶边高光）；图标和字用 `--lg-accent`、650 字重 |
| 按住 / 拖 | 同分段开关；透镜约 70px 高（一行 58px × 1.2），比项左右各宽 7px；透镜底下的图标和字放大到 1.18 倍、加粗到 650、换成主色 |

### 5.4 卡片与表格（实心厚玻璃）

- 卡片：白底、圆角 18、内边距 16×18，`--lg-card-sh`（没有描边线——描边是纸的语言，玻璃的边是光）。卡片之间 14px。
- 表格：同样的容器；表头粘住、12px 半粗次要色、底 `--lg-surface-2`；单元格 9×14，13px；数字列右对齐、等宽数字。
- 行悬停：一块垫在行底下的亮板 + 跟着指针走的指尖光（和按钮同一套；`--lg-sec-glow` 压扁成 150 × 80 的一道竖光），
  不放大、不折射；按下往里收一点（≤ 8px × 3px），不往外鼓。状态用角标：深前景 + 浅同色底、方角 6。
- 角标选色按「这个状态要不要人管」来分，而不是按字面：
  - **good（绿）**：正常的终态或已经顺利推进的状态——完成、成功、已付款、已发货、已到账、在线；
  - **warn（黄）**：还在进行、或需要留意但不算错——进行中、待处理、待审核、即将过期、部分成功；
  - **bad（红）**：出错或需要人马上处理——失败、出错、被拒、已过期、离线；
  - 中性的状态（草稿、已关闭、已取消）不上色，用灰色文字就行。

### 5.5 说明与报错

- **两种话分开**：「为什么会这样」的说明（已退出、会话过期、已保存）用灰色 `.lg-note`；真出错（口令不对、提交失败）才用红色 `.lg-alert`。
  自己点的「退出」被放进红框，会被读成「出了错」。
- 都是「16px 图标 + 一句话」，圆角 12、内边距 8×12、12.5px。不用左侧竖条——竖条贴着圆角会弯过去，很难看。
- 说明放在它解释的东西上面（登录卡里挂在输入框上方），开始打字就收掉；报错放在触发它的按钮下面。

## 6. 弹出层与反馈

| 组件 | 规格 |
|---|---|
| 弹出菜单 | 宽 320、圆角 20、内边距 8、模糊 24、`--lg-tint-menu`；项圆角 14、内边距 9×12；当前项 `--lg-accent-glass` 底 + 实心单选圈；贴着触发它的胶囊下方 8px、右对齐 |
| 命令面板 | 宽 520、圆角 24、模糊 24；输入框 52px；列表项圆角 12；遮罩只调暗（浅 18% / 深 46%）、不模糊；距顶 90px |

| 工具条 | 圆角 18、`--lg-tint-bar`、模糊 12；底部保存条粘住、离底 14px、默认折射 |

## 8. 三档与材质档

| 档 | 看起来 | 动起来 | 什么时候用 |
|---|---|---|---|
| **完整** | 半透明玻璃；Chromium 上背后有内容的玻璃边缘折射；HDR 屏上有高光 | 透镜与滑块流过去，经过的项放大、跟手，按下像果冻；弹出层从上方长出来 | 缺省（没动过开关是「自动」，按「完整」算） |
| **精简** | 面板不透明、不折射，高光环还在 | 透镜与滑块直接到位，不放大、不跟手、不弹出；按钮不浮起 | 远程桌面、虚拟机、老电脑：省显卡，也省远程桌面传画面的带宽 |
| **关闭** | 实色、没有高光环与柔光 | 没有透镜、滑块、指尖光与玻璃提示；悬停叠一层薄暗 | 就是不想要这些效果 |

**三档必须一眼分得出来。** 以后加档位或开关，先截图比一比，肉眼分不出来的就不是一档（`scripts/shoot.mjs` 会验）。
点了开关当场弹一句这一档是什么样。

材质档 l0 / l1 / l2 / l3 的条件见 `principles.md` §9。

## 10. 文案与用词

- 用通用的计算机术语或通俗书面语，不造词、不用黑话。新加一个叫法之前问一句：第一次看到的人能不能不查就懂。
- 三档叫「完整 / 精简 / 关闭」（英文 Full / Lite / Off），开关的提示写清「现在实际是哪一档、为什么」，
  比如「显卡是软件渲染（远程桌面、虚拟机常见），先不折射。点『完整』可强制打开；觉得卡就点『精简』」。
- 危险操作的名字后面挂「危险」两个字，别只靠颜色。
- 说明用陈述句（「已退出登录」），报错说清哪里错、怎么办（「口令不对」而不是「错误 401」）。
